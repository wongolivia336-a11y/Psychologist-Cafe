# Safety review gate

状态：实现了代码护栏，但尚未达到上线签字条件。

## 已完成且可复核

- 危机识别与模型绕过路径仍在 `src/lib/safety.ts` 与 `/api/chat`。
- 危机资源当前只保留国家卫生健康委公布的全国统一心理援助热线 `12356`，并把服务时段改为以当地实际接通提示为准；未能在本轮核验的旧号码已移除。
- 已加入成年确认与知情说明：确认只放在当前浏览器标签页会话，不写入服务端。
- 已补充数据保留说明：本项目代码不把对话、记忆物件或上传图像写入持久化数据库或应用文件；部署平台日志仍需由部署方单独配置与审计。
- `eval/safety/` 提供确定性危机与禁语样例。

## 上线前仍需人工完成

- 由进食障碍方向的临床工作者逐条审阅 `src/lib/personas.ts` 的人格话术、危机文案和上传流程。
- 按部署地区再次实拨或由当地卫生健康部门确认 `12356` 的接线覆盖与时段。
- 由隐私/安全负责人核对部署平台的访问日志、错误日志、请求体采集和保留策略；当前代码没有持久化层，不等于基础设施一定不留日志。
- 做一次人工危机演练：自伤/自杀、持续拒绝进食、催吐、未成年访问和立即危险场景都要记录处置结果。

核验依据：[国家卫生健康委《关于应用“12356”全国统一心理援助热线电话号码的通知》](https://www.nhc.gov.cn/yzygj/c100068/202412/49a1a65386cd4be582d4702fd0926ee8.shtml)。
